# Homework & Grades

A [Chickadee Bandit](https://chickadeebandit.com/app-library/homework-grades) app.

Kids log assignments and grades by subject. Adults see a grade summary per child.

## Features

- Assignments by subject with due dates, status, and grades.
- Overdue items highlighted.
- Per-child grade summary by subject for adults.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-homework-grades/releases/latest/download/bundle.json
```
